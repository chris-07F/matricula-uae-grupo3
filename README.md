# Sistema de Matrícula UAE

## Descripción del proyecto
El Sistema de Matrícula UAE es una propuesta de plataforma web pensada para 
que los estudiantes de la Universidad Agraria del Ecuador puedan matricularse 
de forma más rápida y ordenada, sin tener que hacer filas ni depender de 
formularios físicos. La idea nace de un problema que como estudiantes hemos 
vivido: cuando llega la fecha de matrícula, es difícil saber qué paralelos 
todavía tienen cupo o cuántos créditos llevamos acumulados hasta el momento. 
Con este sistema, el estudiante ingresa con su usuario institucional y puede 
ver en tiempo real las materias disponibles del semestre, el cupo por 
paralelo y confirmar su matrícula desde la misma plataforma. Buscamos que 
sea simple de usar, incluso para quienes no están muy familiarizados con 
sistemas informáticos.

## Funcionalidades principales
- Inicio de sesión con credenciales institucionales
- Selección de materias del semestre
- Visualización de cupos disponibles por paralelo
- Visualización de créditos acumulados por el estudiante
- Confirmación de matrícula desde la misma plataforma
